## New words

- Repository = 仓库
- README = 项目说明书
- Commit = 保存一次修改
- Add file = 添加文件
- Code = 代码入口
- History = 历史记录
- Preview = 预览
- Edit = 编辑

## My understanding

GitHub is like an online project folder.

A repository is a project.

README is the introduction page of the project.

Commit means saving a change.
