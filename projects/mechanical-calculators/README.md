# Mechanical Calculators

This project will record small mechanical engineering calculation tools.

## Planned Tools

- Servo inertia ratio calculator
- Belt drive speed calculator
- Linear guide load calculator
- Cylinder force calculator
- Gear rack selection calculator
- Bolt preload calculator

## Why this project

Mechanical engineers often repeat many calculations in daily work.

I want to use Python and AI to build small tools that can improve mechanical design efficiency.
